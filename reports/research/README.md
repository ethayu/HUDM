# Research Reports

This directory stores historical research provenance: static audits, result
summaries, investigation notes, and follow-up plans captured at the time an
experiment was run.

These files are not live runbooks. Prefer the top-level `README.md`,
`REVIEW_GUIDE.md`, `configs/`, and `scripts/` directories for current workflows.
If a historical report references a script or config that no longer exists,
treat that reference as part of the archived experiment record rather than an
active command to run.
